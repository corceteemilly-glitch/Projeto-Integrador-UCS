# Projeto-Integrador-UCS
**Criação de aplicativo mobile para a venda de produtos rurais.**

  O Objetivo do aplicativo AgroVende é facilitar o registro e o acompanhamento de vendas de produtos rurais. A proposta é oferecer uma ferramenta simples e prática para vendedores e empresas do setor agrícola, permitindo organizar informações comerciais e acompanhar o desempenho das vendas. O sistema permitirá registrar vendas informando o cliente, a quantidade de produtos comercializados e o valor da venda. Além disso, contará com um painel de indicadores gráficos para visualizar os resultados mensais, acompanhar quantidades vendidas e analisar o desempenho comercial.
